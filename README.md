# 台灣 AI 能見度題庫(Taiwan AI Visibility Question Bank)

一組可以直接拿去問 ChatGPT、Gemini、Claude、Perplexity、Google AI 摘要的繁體中文題目,用來量「AI 有沒有提到你的公司、引用了哪些網頁」。

由 [東流生生 FlowEver](https://flowever.tw) 整理,我們自己就用這組題目量測自家公司,方法與結果公開在〈[做 GEO 的公司,自己會被 AI 推薦嗎?我們拿自己測了 30 題](https://flowever.tw/answers/geo-self-test-30-questions/)〉。

## 內容

- `questions.csv`:題目。`v1-` 是 2026-10 第一版基準題(GEO 服務業情境);`v2-` 是依台灣論壇真實問法改寫的白話題與對照題。品牌題的 `{品牌名}` 換成你的公司名稱。
- `record_template.csv`:記錄表欄位。
- `METHOD.md`:怎麼量才不會被騙。
